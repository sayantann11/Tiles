# Tiles

TileDesk ERP: a mobile-first demo ERP for a tiles and sanitary showroom.

Modules: Stock (batch / shade / godown-wise), Sales & GST bills, Quotations (area to boxes with wastage), Expenses, Leads and Credit (udhaar ageing, limits, WhatsApp reminders).

- `index.html`: the app (single static file, no build step). Sample data is generated on first load and kept in the browser.
- `doc/TileDesk-Proposal.pdf`: short owner-facing document with screenshots.
- `screenshots/`: desktop and mobile screenshots.

Run locally: open `index.html` in a browser.
